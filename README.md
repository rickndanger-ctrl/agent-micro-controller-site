# Agent Micro Controller support site

Static support and privacy pages for Agent Micro Controller, whose in-app screen is named Control Deck.

- Support: `index.html`
- Privacy policy: `privacy/index.html`
- Shared styles: `styles.css`

The site has no build step, JavaScript, analytics, external fonts, or embedded third-party assets. Links to GitHub support and the privacy policies of relevant services are ordinary outbound links.

For a local preview, run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.

Intended GitHub Pages address: https://rickndanger-ctrl.github.io/agent-micro-controller-site/

This repository contains support and privacy information only. It contains no application binaries, pairing information, or private application source. Publishing the site does not indicate that an app release is available through any particular distribution channel.
